## Как искать

- По теме: `grep -rn "<слово>" docs/Science_lab docs/change-acceptance.md`, например «ворота», «авто-навыки», «кэш».
- По истории: `git log --oneline --grep "A/B pilot"`, `git log -- docs/Science_lab`.
- По числам: `measurements/<дата>-<имя>/bench.json` (ключи `A`/`B` → `T1..T5`, `plan`, `background`) и таблицы в
  `AB-PILOT-2026-10-28.md`.
- По сессиям и воротам: запросы к `history.db` (примеры в `NEXT-SESSION.md`, таблица «Как проверить»).

## Как добавлять результаты

1. Данные: `measurements/<дата>-<имя>/` (вывод приборов и свой `RESULTS.md`).
2. Вывод: новый документ или раздел, строка в таблицу «Куда смотреть» выше.
3. Решение по изменению: карточка и строка в `../change-acceptance.md` §7.
4. Скрытые тесты, их пути и пороги в репозиторий не писать: клоны, которые видят агенты, берутся из него.
